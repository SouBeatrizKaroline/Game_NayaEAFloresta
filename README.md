# Naya e a Floresta

Uma pequena caminhada em pixel art para ouvir a floresta e devolver sete estrelas ao céu. Pelo caminho, Naya encontra uma coruja, um cervo e uma árvore antiga.

## Como jogar

Abra [o jogo no navegador](https://soubeatrizkaroline.github.io/Game_NayaEAFloresta/) e clique em **começar a caminhada**. Use as setas ou WASD para andar; perto de um personagem, pressione espaço para escutar. No celular, use as setas na tela e o botão **escutar**. O botão de som permite silenciar os efeitos.

O jogo roda direto no navegador, sem instalação ou dependências obrigatórias.
