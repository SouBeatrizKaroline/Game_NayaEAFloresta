# Naya: Floresta de Estrelas

Um jogo curto em pixel art sobre caminhar devagar e devolver as estrelas ao céu.

## Como jogar

Abra `index.html` no navegador. Use as setas ou **WASD** para caminhar. Encoste nas estrelas para encontrá-las.

O projeto é feito apenas com HTML, CSS e JavaScript, sem build ou dependências obrigatórias.
